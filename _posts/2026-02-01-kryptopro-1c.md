# Установка КриптоПро CSP 5 на Ubuntu Server (без GUI) и настройка для работы с 1С

## 1. Подготовка системы

Установите необходимые зависимости:

```bash
sudo apt install -y pcscd opensc
```

## 2. Загрузка и распаковка дистрибутива

1. Зарегистрируйтесь на сайте КриптоПро (если нет учётной записи).
2. Скачайте дистрибутив **КриптоПро CSP 5** для Linux (формат `.deb`, архитектура `amd64`).
3. Переместите архив на сервер (например, через `scp`).
4. Распакуйте архив:
   ```bash
   tar -xvf linux-amd64_deb.tgz
   cd linux-amd64_deb
   ```

## 3. Установка КриптоПро CSP


Запустите установку в консольном режиме:
```bash
sudo ./install.sh
```

**Что произойдёт:**
- Установятся базовые пакеты (`lsb-cprocsp-base`, `lsb-cprocsp-capilite`, `lsb-cprocsp-kc1-64`, `lsb-cprocsp-rdr-64` и др.).
- Будут настроены службы и библиотеки.


**Важно:**  
- Не выбирайте пакеты с GUI (`cprocsp-cptools-gtk`, `cprocsp-rdr-gui-gtk`), если сервер без графической оболочки.
- Для работы с токенами/смарт‑картами установите дополнительные пакеты (см. раздел 5).

## 4. Активация лицензии


После установки введите серийный номер лицензии если есть:
```bash
sudo /opt/cprocsp/bin/amd64/cpconfig -license -set ВАШ_СЕРИЙНЫЙ_НОМЕР
```

Чтобы проверить статус лицензии:
```bash
/opt/cprocsp/bin/amd64/cpconfig -license -view
```

## 5. Установка дополнительных пакетов (по необходимости)


Для работы с конкретными устройствами:

- **Рутокен:**
  ```bash
  sudo apt install -y cprocsp-rdr-rutoken-64
  ```
- **JaCarta:**
  ```bash
  sudo apt install -y cprocsp-rdr-jacarta
  ```
- **Поддержка PKCS#11:**
  ```bash
  sudo apt install -y cprocsp-rdr-cryptoki
  ```
- **Корневые сертификаты УЦ (опционально):**
  ```bash
  sudo apt install -y lsb-cprocsp-ca-certs
  ```

## 6. Установка корневых и промежуточных сертификатов

### Вариант 1: Через командную строку

1. **Корневой сертификат** (в хранилище `mRoot`):

   ```bash
   /opt/cprocsp/bin/amd64/certmgr -inst -cert  -store mRoot -file /путь/к/корневому.cer
   ```

2. **Промежуточный сертификат** (в хранилище `mca`):

   ```bash
   /opt/cprocsp/bin/amd64/certmgr -inst -cert -store mca -file /путь/к/промежуточному.cer
   ```

3. **Личный сертификат usr1cv8** 

   ```bash
   su usr1cv8
   /opt/cprocsp/bin/amd64/certmgr -inst -cert -file /путь/к/личный.cer
   ```

**Проверка установки:**
```bash
/opt/cprocsp/bin/amd64/certmgr -list -store uRoot
/opt/cprocsp/bin/amd64/certmgr -list -store uca
```

## 8. Настройка КриптоПро для 1С

### Шаг 1. Проверка доступности криптопровайдера

Убедитесь, что КриптоПро виден в системе:
```bash
/opt/cprocsp/bin/amd64/csptest -enum -verify
```

### Шаг 2. Настройка в 1С

1. В 1С перейдите:  
   **Администрирование** → **Обмен электронными документами** → **Настройки электронной подписи и шифрования**.
2. На вкладке **«Программы»**:
   - Добавьте **КриптоПро CSP (ГОСТ 2012/256)**.
   - Укажите путь к библиотеке (обычно `/opt/cprocsp/lib/amd64/libcapi20.so`).
3. На вкладке **«Сертификаты»**:
   - Нажмите **«Добавить»** → **«Из установленных на компьютере»**.
   - Выберите нужный сертификат из списка.
4. Укажите пользователей, которым разрешён доступ к сертификату.
5. Сохраните настройки.

### Шаг 3. Проверка работы

1. В 1С попробуйте подписать тестовый документ.
2. Если возникает ошибка, проверьте:
   - Наличие всех сертификатов в цепочке.
   - Правильность пути к библиотеке КриптоПро.
   - Статус лицензии (`cpconfig -license -view`).

## 9. Дополнительные команды для диагностики


- **Список контейнеров:**
  ```bash
  /opt/cprocsp/bin/amd64/csptest -keys -enum
  ```
- **Проверка сертификата в контейнере:**
  ```bash
  /opt/cprocsp/bin/amd64/cryptcp -verifycert -cont "Имя_контейнера"
  ```
- **Тестовая подпись файла:**
  ```bash
  /opt/cprocsp/bin/amd64/cryptcp -signf /путь/к/файлу.txt
  ```

## 10. Устранение типичных проблем

- **Ошибка «Сертификат не доверен»**:  
  Убедитесь, что корневой и промежуточные сертификаты установлены в `uRoot` и `uca`.
- **Не виден токен**:  
  Проверьте работу службы `pcscd`:
  ```bash
  sudo systemctl restart pcscd
  sudo systemctl status pcscd
  ```
- **Нет доступа к контейнеру**:  
  Проверьте права на каталог `/var/opt/cprocsp/keys/`:
  ```bash
  sudo chown -R ваш_пользователь:ваш_пользователь /var/opt/cprocsp/keys/
  ```

## Итог

1. Установите КриптоПро CSP через `install.sh`.
2. Активируйте лицензию.
3. Импортируйте корневые и промежуточные сертификаты.
4. Настройте цепочку для контейнеров (если требуется).
5. Добавьте КриптоПро и сертификаты в настройки 1С.
6. Проверьте работу через тестовую подпись.
