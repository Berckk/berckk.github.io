# Как получить событие `lic_binding` в технологическом журнале 1С

## 1. Подготовка файла конфигурации

Создайте (или отредактируйте существующий) файл **`logcfg.xml`** и поместите его в каталог:  
`C:\Program Files\1cv8\<версия>\bin\conf`

## 2. Настройка содержимого файла

Вставьте в `logcfg.xml` следующую структуру для сбора событий `lic_binding`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<config xmlns="http://v8.1c.ru/v8/tech-log">
    <log history="72" location="C:\LOG">
        <event>
            <eq property="name" value="LIC_BINDING"/>
        </event>
    </log>
</config>
```

### Ключевые параметры

- **`history="72"`** — время хранения логов в часах (в примере — 3 суток);
- **`location="C:\LOG"`** — путь к каталогу для сохранения логов;
- **`<eq property="name" value="LIC_BINDING"/>`** — указание на сбор событий `lic_binding`.

## 3. Создание каталогов

Убедитесь, что:
- папка `C:\LOG` существует;
- у сервера 1С есть права на запись в эту папку.

## 4. Активация журнала

1. Перезапустите сервер 1С или клиентское приложение.
2. Через 1–2 минуты в `C:\LOG` появятся подпапки с логами.

## 5. Как выглядит событие в логах

В файлах логов событие представлено строкой формата:

```
<дата_время>,<идентификатор_процесса>,Event=LIC_BINDING,Data='<детали_события>'
```

Пример:
```
20240515143015.123456-0,rphost_1234,Event=LIC_BINDING,Data='license_type=network,user=Ivanov,computer=PC01,binding_method=ip,ip=192.168.1.100,result=success'
```

### Расшифровка полей

- `<дата_время>` — дата и время события в формате `ГГГГММДДЧЧММСС.микросекунды`;
- `<идентификатор_процесса>` — имя процесса (например, `rphost_1234`);
- `license_type` — тип лицензии (например, `network`, `single`);
- `user` — имя пользователя, запросившего лицензию;
- `computer` — имя компьютера, с которого запрошена лицензия;
- `binding_method` — метод привязки (например, `ip`, `mac`, `hardware_key`);
- `ip` — IP‑адрес компьютера (если метод привязки — `ip`);
- `result` — результат операции (`success` или `failure`).

## 6. Проверка работы

1. Откройте папку `C:\LOG`.
2. Найдите подпапку с именем процесса (например, `rphost_1234`).
3. Откройте самый свежий файл `.log` в этой папке.
4. Поищите строки с `Event=LIC_BINDING`.

## 7. Типичные проблемы и их решение

| Проблема | Решение |
|--------|--------|
| Нет событий в логах | Проверьте: <br> - правильность написания `LIC_BINDING`; <br> - размещение `logcfg.xml` в нужной папке; <br> - перезапуск сервера 1С после изменений. |
| Ошибка доступа к папке | Предоставьте права на запись в `C:\LOG` для учётной записи сервера 1С. |
| Быстрый рост объёма логов | - Сократите `history` (например, до `24`); <br> - добавьте фильтры по другим событиям. |

## 8. Анализ данных

Для анализа событий `lic_binding` обращайте внимание на:

- **Частота событий** — аномально частые запросы могут указывать на проблемы с лицензированием;
- **Результаты (`result`)** — наличие записей `failure` сигнализирует о проблемах с получением лицензий;
- **Методы привязки (`binding_method`)** — убедитесь, что используются ожидаемые методы;
- **Пользователи и компьютеры** — проверьте, соответствуют ли запросы ожидаемым устройствам и пользователям.
